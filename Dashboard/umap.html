Reading the UMAP Plot

Each point is a student reduced from {{ data.n_features }} features to 2 UMAP dimensions. Points close together share similar feature profiles — UMAP respects local neighbourhood structure, unlike PCA. Colour shows placement: red = Not Placed, blue = Placed. Visible colour clusters mean UMAP has found a real structure that predicts placement.

UMAP Embedding Coloured by Each Feature (n_neighbors=30)

How to Read These Plots

Regions of the UMAP that have a consistent colour (high or low values of a feature) indicate that UMAP has captured a real structure in the data related to that feature. If a feature's colour appears random across the embedding, that feature isn't driving cluster structure.

PCA vs UMAP Side-by-Side

PCA

  • Linear transformation only
  • Preserves global variance (spread)
  • Fast, deterministic
  • Interpretable (loadings)
  • Can miss non-linear cluster shapes

UMAP

  • Non-linear, graph-based
  • Preserves local & global structure
  • Slower, stochastic (random_state needed)
  • Less interpretable axes
  • Reveals complex cluster geometry
