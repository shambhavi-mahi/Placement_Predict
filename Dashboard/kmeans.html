How K-Means Works

K-Means partitions students into K groups by minimising within-cluster variance (inertia). Each iteration reassigns every student to the nearest centroid, then recomputes centroids, until convergence.

  • Use the Elbow plot to find where adding more clusters gives diminishing returns — the bend in the inertia curve.
  • Confirm with the Silhouette Score: values closer to 1 mean well-separated, compact clusters.
  • Features are standardised (zero mean, unit variance) before clustering so no single scale dominates.
