How to Read This Plot

Each point is sorted by its distance to its {{ data.min_samples }}-th nearest neighbour. Points in dense regions (left side) have a small k-distance. Points in sparse regions (right side) have a large k-distance.

The elbow marks the boundary between dense and sparse regions. Setting eps at the elbow captures the dense clusters while labelling the sparse tail as noise.

Suggested eps from elbow: {{ data.suggested_eps }}

Three Types of Points

🟢 Core Point
Has ≥ min_samples neighbours within eps. Anchors and expands clusters.
🟡 Border Point
Within eps of a core point but not core itself. Part of that cluster, doesn't extend it.
⚫ Noise Point
Not a core point, not within eps of one. Labeled –1. Explicitly an outlier.

eps Too Small vs Too Large

Too small: most points can't find enough neighbours within eps, so everything becomes noise — no clusters form.
Too large: all points are neighbours of each other; everything merges into one giant cluster with zero noise — the algorithm becomes trivial.
Just right: the elbow eps separates genuinely dense regions (clusters) from sparse regions (noise).

DBSCAN vs K-Means vs Hierarchical

  • K-Means — requires K upfront, forces all points into clusters, assumes spherical blobs.
  • Hierarchical — requires K (cut height), forces all points into clusters, can find non-spherical clusters.
  • DBSCAN — no K needed, explicitly labels outliers as noise, handles arbitrary shapes, but sensitive to eps.
