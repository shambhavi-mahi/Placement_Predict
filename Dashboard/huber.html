OLS vs Huber on Corrupted Data

Why this works: Standard Linear Regression (OLS) minimizes squared errors, which means extreme outliers pull the line heavily towards them. Huber Regression uses an absolute error loss for large deviations, ignoring their extreme pull while still fitting the main trend cleanly.
