📖 How to Read Coefficients

  • β > 0 (positive): Higher feature value → higher log-odds of placement → odds ratio > 1.
  • β < 0 (negative): Higher feature value → lower log-odds of placement → odds ratio < 1.
  • |β| magnitude: Larger absolute value = stronger influence on the prediction.
  • Odds Ratio (OR): A 1-standard-deviation increase in the feature multiplies the placement odds by OR.
  • Standardization matters: Coefficients are comparable only because features were scaled to unit variance.
