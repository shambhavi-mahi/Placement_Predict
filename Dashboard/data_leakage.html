True Risk (Generalisation Error)

R_true(f) = E{(x,y)~P}[ L(f(x), y) ]

Expected loss over the unknown true joint distribution P(X, Y). This is what we ultimately care about — how the model performs on future unseen data. We can never compute it directly; we can only estimate it.

Empirical Risk (Training Error)

R_emp(f) = (1/N) × ∑i=1..N L(f(xi), yi)

Average loss computed on the observed sample dataset D. A model can drive empirical risk to zero just by memorising training data (overfitting). The validation/test set gives an unbiased estimate of true risk.

Why the Gap Matters

The difference R_true − R_emp is the generalisation gap. A large gap means overfitting. Regularisation, cross-validation, and sufficient data all work to close this gap. Leakage artificially deflates R_emp, making you think the gap is small when it isn't.

Why Pipeline Prevents Leakage

✖
Wrong (leakage)
Fit StandardScaler on all data, then split. The scaler has seen mean/std of test fold → inflated CV scores.
✔
Correct (pipeline)
Inside each fold, pipeline.fit(X_train) → scaler learns only from that fold's training rows → pipeline.transform(X_val) uses those stats. Validation fold is never touched during fitting.

StratifiedKFold ensures each fold has the same class ratio as the full dataset. This is critical when one class (e.g., "Not Placed") is rarer — random splits might accidentally put all "Not Placed" samples in one fold, distorting CV estimates.
