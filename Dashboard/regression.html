📐 Linear Regression

Finds coefficients that minimise the sum of squared residuals between predicted and actual salary values.

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ
Loss: MSE = (1/m) Σ(ŷᵢ − yᵢ)²

🔣 Normal Equation

Closed-form solution — directly computes the optimal weights in one shot without iterating.

θ = (XᵀX)⁻¹ Xᵀy
Exact solution. No learning rate needed.

📉 Batch Gradient Descent

Iteratively updates weights using the gradient of the cost over ALL training samples each epoch.

θ := θ − α · (2/m) Xᵀ(Xθ − y)
α = 0.01 · Epochs = 2,000
