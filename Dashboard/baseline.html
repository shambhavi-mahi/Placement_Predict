🤔 What is a Baseline Model?

A baseline model is the simplest possible predictor — it requires no features, no training loop, and no hyperparameter tuning. The majority-class baseline simply looks at the training labels and always predicts whichever class appears most often.

For this dataset the majority class is {{ baseline.majority_label }} ({{ baseline.placed_pct if baseline.majority_class == 1 else baseline.not_placed_pct }}% of samples). So the baseline guesses "{{ baseline.majority_label }}" for every student.

If a sophisticated algorithm cannot surpass this number, it is not actually learning anything useful — it might as well flip a biased coin.
